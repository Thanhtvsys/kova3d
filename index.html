Hướng Dẫn Đưa App Lên GitHub Pages Miễn Phí

Chỉ với 4 bước đơn giản trong 2 phút, bạn sẽ có website riêng chạy vĩnh viễn không tốn tiền server.

1

Tạo Repository mới trên GitHub

Truy cập vào GitHub.com và đăng nhập. Nhấn nút New (hoặc dấu + chọn New repository).

  • Repository name: nhập adfree-tiktok-tube
  • Chọn chế độ: Public (bắt buộc để dùng free)
  • Bấm nút Create repository ở cuối trang
2

Tạo tệp index.html

Tại giao diện Repository vừa tạo:

  1. Nhấn vào liên kết creating a new file.
  2. Đặt tên tệp chính xác là: index.html
  3. Dán toàn bộ mã nguồn HTML này vào ô nội dung tệp.
  4. Nhấn nút Commit changes... → chọn Commit changes.
3

Kích hoạt GitHub Pages

Bật tính năng phát website công khai:

  1. Chuyển sang tab Settings của Repository.
  2. Ở danh mục bên trái, cuộn xuống chọn Pages.
  3. Tại Build and deployment → Branch: chọn main (hoặc master), thư mục giữ nguyên /(root).
  4. Nhấn Save.
4

Truy cập Website của bạn

Sau khoảng 1-2 phút, GitHub sẽ tạo cho bạn link web có định dạng:

https://<your-username>.github.io/adfree-tiktok-tube/
